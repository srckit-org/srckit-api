# srckit-api

> Part of [srckit](https://github.com/srckit-org/srckit) — developer tools suite

Parse API endpoint definitions and manage collections.

## Features

- **Runner** — Parse method+path definitions into structured endpoints
- **Collection** — Save and manage API endpoint collections with localStorage persistence

## Tech Stack

React 19 · MUI 9 · Tailwind CSS 4 · TypeScript 6 · Vite 8

## Getting Started

```bash
npm install
npm run dev
```
